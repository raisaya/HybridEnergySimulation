# HybridEnergySimulation

## Description:
A Python program simulating an off-grid hybrid energy system with solar PV panels, a diesel generator and battery storage. Visualizes energy production, consumption, battery SOC, and contribution of each source over 24 hours. Perfect for learning and exploring energy systems.

---

## Features
- Solar PV and diesel production modeling  
- Battery State of Charge (SOC) simulation  
- Load (network consumption) visualization  
- Pie chart showing energy contribution of each source  

---

## Requirements
- Python 3.x  
- NumPy  
- Matplotlib
